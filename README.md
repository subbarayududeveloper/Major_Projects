## 📌 Projects Overview

### 🔹 Project 01 – PAN Card Tampering Detection

**Description:**  
An image processing–based system to detect tampering in PAN Card images by comparing original and suspected documents using Structural Similarity Index (SSIM).

**Technologies:**  
Python, OpenCV, scikit-image, NumPy, Google Colab

**Key Features:**

- Automated PAN card forgery detection
- Structural similarity analysis
- Visual highlighting of tampered regions
